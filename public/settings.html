About InboxFlow

InboxFlow — AI-Powered Email & Productivity Assistant

Version 1.0.0 • Designed with Corporate Modernism & Minimalism

🚀 What is InboxFlow?

InboxFlow is an intelligent SaaS productivity dashboard engineered to turn chaotic email inboxes into structured action items, deadlines, and smart follow-up workflows.

🛠️ Full Architecture Stack
  • Frontend: HTML5, Custom CSS Tokens, Bootstrap 5, Vanilla JavaScript.
  • Backend: Node.js + Express.js REST API.
  • Email Integration: Google OAuth2 + Gmail API (real-time thread syncing & reply drafting).
  • AI Engine: Groq API with multi-model fallback (Llama 3 & GPT models) for high-speed categorization, summaries, and reply generation.
  • Database: Supabase PostgreSQL storing tasks, deadlines, follow-ups, and user analytics.
✨ Core Capabilities
📥 Smart AI Inbox: Auto-assigned HIGH/MEDIUM/LOW priority tags and intent labels.
🧠 Thread Intelligence: Executive 3-bullet summaries & priority scores.
📅 Deadline Tracker: Calendar view, approaching alerts & 1:00 PM daily reports.
🛡️ Spam Shield: Multi-tier phishing and unsolicited promo detector.
